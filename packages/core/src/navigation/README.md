# Navigation primitives

Import factories from `@pwa-design-system/core` and load `@pwa-design-system/core/navigation.css` after the generated token CSS. Every factory returns `{ element, destroy() }`; append the element to the document, call `destroy()` to release listeners, and remove the element yourself. Labels and content are plain text, never HTML. All families currently have one visual size and style. Loading states, configurable size variants and per-widget disabled states are not provided unless explicitly listed below.

- `createTabs({ label, tabs, selectedIndex?, onChange? })`: `label` names the tab list. `tabs` contains at least one `{ label, content }` text pair. The selected index defaults to `0`; `select(index)` changes it without moving focus or calling `onChange`. Click and ArrowLeft/Right, Home and End immediately select and call `onChange(index)` only when the selected index changes. The selected tab and panel are linked with IDs. Individual disabled tabs, vertical orientation and lazy/interactive panel content are not supported.
- `createBreadcrumb(items, label?)`: an array of `{ label, href? }`. Non-final items require HTTP(S) or relative links; the final item is the current page. The navigation label defaults to `Breadcrumb`. Links have their native keyboard behavior. There are no disabled links or loading states.
- `createMenu({ label, items })`: a button with at least one `{ label, onSelect, disabled? }` item. Disabled defaults to false; disabled items remain focusable and do not activate. ArrowDown/Up opens and moves through items, Home/End moves to the endpoints, Escape closes and restores the trigger, and Tab closes. Requires the native Popover API and throws explicitly if unavailable. A containing dialog closing dismisses the menu; a queued close event from an earlier dialog lifetime does not dismiss a menu after reopening. There are no nested menus or typeahead.
- `createPagination({ page, totalPages, onChange, label? })`: one-based page and positive total count. The label defaults to `Pagination`; Previous/Next become disabled at boundaries. Buttons announce current state and call `onChange(page)` for user changes; `setPage(page)` updates without a callback. Numeric page buttons and loading states are not supported.
