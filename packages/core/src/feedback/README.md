# Feedback primitives

Import factories from `@pwa-design-system/core` and load `@pwa-design-system/core/feedback.css` after generated token CSS. All content and labels are plain text. Every factory returns `{ element, destroy() }`; call `destroy()` to release listeners and remove the element yourself. These primitives have a single size and presentation except for alert tones. Loading states and other style variants are not provided.

- `createDialog({ title, description, closeLabel?, onClose? })` returns a native `<dialog>` plus `open(opener?)` and `close()`. Append it before opening. Pass the connected, enabled invoking element to `open(opener)` for pointer activation, because some browsers do not focus buttons on click. Without it, `open()` records the current active element. On opening, focus moves to the close button; Escape or Close dismisses the modal and attempts to return focus to that element if still connected. The required title and description provide the accessible name and description; `closeLabel` defaults to `Close`. Native modal behavior makes the background inert; Tab and Shift+Tab wrap within the dialog. There is no arbitrary HTML or custom action API yet.
- `createAlert({ message, tone?, assertive? })` provides a static message by default; `tone` is `info` (default), `success`, `warning` or `danger`. For urgent dynamic content set `assertive: true`, mount the empty alert, then call `setMessage(message)` so assistive technology can detect a change. Status does not depend on color alone: provide clear message text. This component does not auto-dismiss.
- `createToast({ message, dismissLabel?, onDismiss? })` creates a polite status and a keyboard-operable dismissal button. `dismissLabel` defaults to `Dismiss`; no timeout is applied. Its live-region text is added after the element enters the document, including delayed mounting. Automatic announcement behavior depends on browser and assistive technology; manual verification remains necessary. Destroy unused instances to stop their attachment observer.
