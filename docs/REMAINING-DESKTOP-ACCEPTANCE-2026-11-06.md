## Confirmed regression and correction

The first text-only run completed 14 functional assertions but **failed visual editing acceptance**. Independent review found Back to top covering the focused invalid Token override. The [original native geometry](evidence/remaining-desktop-acceptance-2026-11-06/firefox/text200-collision.json) measured input y=699–787 and floating action y=651–739, intersection about **8,104 CSS px²**; `elementFromPoint` in that intersection returned `#scroll-to-top`. Merely checking that the input was inside the viewport had missed the obstruction.

The private shell correction suppresses floating navigation while an interactive/editable control inside main has focus. Focus exit, document scroll, resize and route resets recalculate visibility. Documentation behavior and the topbar Studio-theme control remain independent; Back to top remains available after editing and still returns focus to the page heading. The Token Inspector also uses a named, font-relative `14em` container fallback to stack Default/Resolved values when enlarged text makes the value column cramped. Tokens, component public APIs, React boundaries, palette and persistence rules are unchanged; no dependency was added and text enlargement was not disabled.

The original native failure and deterministic baseline failure are retained. The browser regression checks deep-scroll threshold, focused-input hit testing, valid/invalid edits, floating-action recovery and route transitions; it does not just compare implementation selectors. A separate check protects readable value lines. The [final native candidate](evidence/remaining-desktop-acceptance-2026-11-06/firefox/final-candidate/summary.json) passed **14 primary flows plus two explicit regressions** under actual Zoom Text Only 200%.
