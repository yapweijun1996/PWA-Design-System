# AI agent integration rules

Read `packages/agent-contract/design-system.json` before generating UI, and inspect `component-contracts.json` for current APIs. `validation-rules.json` lists the machine-readable guidance; these rules do not grant access, run code or replace current repository instructions. Reuse core components and semantic tokens, preserve responsive behavior and accessible interactions, avoid duplicate components and arbitrary values, and report deviations with actual test evidence. The private [approved text glyph registry](../packages/icons/README.md) contains a limited set; custom glyphs require review. The legacy string API and runtime consumer code are not statically enforced.

The optional `icons` field extends the v1 schema without requiring the field in older schema-valid documents. Current-contract verification also compares the complete content with the current registry and rules, so a previously exported contract without the new icon metadata will be reported as out of date; export a current contract when integrating the updated system.

The design contract and its JSON Schema are generated/validated against the current registry, package metadata, token axes and rules. The static Ajv-generated validator avoids runtime schema compilation; its MIT notice is in `packages/agent-contract/AJV-LICENSE.txt`. Imported contract files are bounded, treated as untrusted JSON and verified against the current registry. They are never evaluated or applied as instructions. Validation confirms structure and current references; it does not prove UI behavior, accessibility conformance or safety of unrelated code.

From the repository root, run `npm run contracts:check`, `node scripts/build-agent-validator.mjs --check` and `node scripts/build-agent-contract.mjs --check` alongside the relevant type, unit and browser tests. The Studio's AI Agent Rules page can export a contract, token CSS, agent instructions, component API reference and integration guide; these exports do not publish packages or deploy the Studio.
